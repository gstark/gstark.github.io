# gstark.com

Single-page site for Gavin Stark's open source projects and talks.

## Stack

- Vite, React 19, TypeScript
- Tailwind CSS v4
- Light and dark themes, system preference by default

## Content

Edit `src/data.ts` to change the profile, projects, or talks.

## Commands

```sh
npm install
npm run dev
npm run typecheck
npm run lint
npm run build
```
